### Сделано

  при активном токене и наличии логинов для сайта / при открытии Search).
  Общий фактор — popup менял размер после асинхронной загрузки контента. Firefox

  (DPI/мульти-монитор) такой ресайз закрывает панель. Фикс: фиксированный размер
  popup 400×540 (на Android — full page), списки скроллятся внутри, нативные
  `title`-тултипы не используются (они открывают отдельный popup-слой).
  Подтвердить на проблемном ПК не удалось — нужна проверка пользователем.

- Удаление логина: кнопка с подтверждением, удаляет KV v2 metadata (все версии).
- Генератор паролей: crypto-random без смещения, длина 8–128, наборы символов,
  «без похожих символов», Copy и Fill on page (поля new-password / фокус + confirm).
- Поиск: раньше каждый поиск заново читал весь base path. Теперь индекс
  (без паролей) кэшируется в памяти background на 2 мин, фильтрация локальная
  при вводе, запросы к Vault с ограниченным параллелизмом (16).
- 401/403 от Vault больше не превращается в «нет логинов» — показывается
  «Vault session expired».

## 2026-10-23 — многошаговый вход (Google и т.п.)

Проблема: форма только с логином → «Далее» → форма только с паролем. Код находил поля только
парой (логин + пароль), поэтому на обоих шагах не было ни подсказок, ни предложения сохранить.

Сделано:
- `findLoginFields` возвращает и неполные формы: только логин (нужен явный признак —
  autocomplete username/email, type=email, name/id user/login/email/identifier, чтобы не цеплять
  поиск по сайту) или только пароль.
- Первый шаг: меню подсказок, выбор заполняет только логин; логин (выбранный или введённый +
  Enter/Next/Continue/Далее/Продолжить) запоминается в `storage.session` по вкладке и origin, на 10 мин.
- Второй шаг: меню показывает только учётку с этим логином (или логином из скрытого/readonly поля
  страницы), fill заполняет только пароль; при отправке пароль сохраняется с логином первого шага.
- Попутно: поиск поля логина пропускал чекбоксы вроде "remember_user", autocomplete="username webauthn"
  (Google) теперь распознаётся.

Проверено: unit-тесты (77), e2e в Chromium — собранный content.js на имитации Google-входа,
3 сценария (выбор из меню / ручной ввод / скрытое поле логина).

Ограничение: если сайт после входа сразу уводит на другой origin (Google → myaccount),
«Save login?» покажется при следующем заходе на страницу входа — так было и раньше.
